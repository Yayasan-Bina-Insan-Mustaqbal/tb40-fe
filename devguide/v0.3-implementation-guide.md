# v0.3 Implementation Guide: Adaptive Assessment & Persistence Engine

This guide details the frontend integration architecture for **v0.3 Adaptive Assessment & Persistence Engine** in `tb40-fe`.

---

## 1. Overview of Architecture

Version 0.3 replaces legacy client-side calculation and stateless endpoints with a server-driven state machine backed by **PocketBase** (`api-tb40`).

### Key Features:
- **Fast-Track Anonymous Start**: Users choose Adult (`tb40`) or Child (`tb40anak`) version from landing page CTAs without filling registration forms upfront.
- **Stateful Submissions (`sub_xxxxxxxx`)**: State, steps, and timestamp confirmations are preserved automatically in PocketBase.
- **Profile Gate Modal**: Unlocks Tier 3 (18 sub-groups) when the server returns `next_tier: "profile_required"`, capturing subject name, age/birthdate (with automatic demographic version routing), and Observer Mode choices (*"Apakah tes ini untuk Diri Sendiri atau Orang Lain?"*).
- **Debounced Auto-Save & Timestamping**: Range sliders automatically auto-save interactions to `POST /evaluate` with timestamp confirmations (*"Tersimpan pada HH:mm:ss"*).
- **Explicit Shorthand Share URLs**:
  - `?id=sub_ahmad_1784758720&tier=3&type=tb40&name=Ahmad&t1=70&t2=kcr&t3=85,70...`
- **Fallback Subject Name**: Defaults to `"Anda"` for `tb40` and `"Kamu"` for `tb40anak`.
- **2-Pane Event Admin Dashboard**: Left pane for cohort overview summary, advanced multi-filters, batch CSV/JSON export, and multi-selected PDF print export. Right pane for live participant report preview.

## 2. API Endpoints Reference

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `POST /api/v0.3/submissions` | `POST` | Initialize fast-track anonymous or profiled submission session. |
| `GET /api/v0.3/submissions/:id` | `GET` | Fetch submission status, current tier, and halfway report. |
| `POST /api/v0.3/submissions/:id/evaluate` | `POST` | Stepwise evaluation turn & debounced auto-save. |
| `PATCH /api/v0.3/submissions/:id/profile` | `PATCH` | Update profile info (`subject_name`, `birth_date`/`age`, `is_observer`), unlocking Tier 3. |
| `PATCH /api/v0.3/submissions/:id/contact` | `PATCH` | Lock answers & attach contact info (`email`, `phone`). |
| `GET /api/v0.3/submissions/:id/share` | `GET` | Fetch public read-only report result. |
| `GET /api/v0.3/:type/schema` | `GET` | Retrieve dynamic question schemas with qualitative emojis. |
| `GET /api/v0.3/events/:eventId/submissions` | `GET` | Batch export of all submissions for an event cohort. |
